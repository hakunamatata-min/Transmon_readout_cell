# HFSS model

`readout_cell_v2.aedt` is the original project with six designs: Eigen and Driven
for W160, W200, and W240. It was generated using AEDT 2026 R1.

The project file is included byte-for-byte. Large solver caches, lock files,
automatic backups and earlier calibration projects are omitted. The project
preserves geometry and solver settings; to recover missing field solutions or
run EPR again, solve the eigenmode designs in a licensed AEDT installation.

See `../docs/REPRODUCING.md`. Use a new project name after changing geometry,
because existing designs are reused by the runner.
