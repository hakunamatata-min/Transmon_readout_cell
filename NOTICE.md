# Provenance and third-party references

This repository uses the standard components exposed by Quantum Metal / Qiskit
Metal, and the APIs of PyAEDT, pyEPR, QuTiP, NumPy, SciPy, pandas and Matplotlib.
These packages are installed as dependencies; their source distributions and
licenses are not replaced or relicensed by this project.

The geometry and analysis workflow follows the official Metal transmon–resonator
and hanger-resonator tutorial patterns, with project-specific dimensions,
placement, port handling, compatibility adapters, fitting, and documentation.
See the tutorial links and original research references in README.md.

No repository-wide license has been selected for this portfolio release. The
repository owner may add one later. No textbook PDF, Ansys installer/license,
third-party package source tree, or private credentials are distributed here.

Public JSON provenance paths are rewritten relative to the project root. The
numerical data, sampled fields and included AEDT model retain their original
contents. Solver caches, personal logs, previous calibration versions and pyEPR
internal serialized containers are not required for viewing and are excluded.
