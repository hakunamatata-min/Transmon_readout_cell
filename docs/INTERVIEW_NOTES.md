# 教材对应与面试提纲

以下为学习用教材的印刷页码；教材 PDF 不包含在本仓库中。

| 问题 | 可以直接讲的回答 | 教材定位 |
|---|---|---|
| 两处耦合是什么？ | 焊盘调整量子比特—谐振器耦合；馈线耦合区影响外部线宽与加载Q。本次只改变前者。 | Fig.24.2–24.3，第345–346页；§24.3.2.3，第348–349页 |
| HFSS频率为何不是最终f01？ | Josephson结在线性求解中被电感代替。EPR基于结参与率加入非线性，再从量子能级差提取跃迁频率。 | 式(19.6)、(19.18)，第266–268页；§24.3.3.3，第350–351页 |
| χ与2χ怎样区分？ | 相对中心角频率的位移为正负χ，完整状态间隔为∣2χ∣/(2π)。200 μm间隔约5.054MHz，对应χ/(2π)约−2.527MHz。 | 式(22.18)、Example22.1，第318页 |

| 耦合更强为何也更容易衰减？ | 量子比特激发更强地混合读出模态，后者存在向馈线泄漏能量的通道。用单模Purcell模型量化代价。 | T₁见式(25.4)，第359页；Purcell公式为补充模型 |
| 选择哪组？ | 按间隔达到线宽、再优先降低读出线路衰减的筛选准则，160 μm是下一步验证候选；不宣称全局最优。 | §24.3.4，第351–352页 |

## 重要边界

不能说“实际器件T₁为70μs”“保真度提高78%”或“HFSS已直接模拟两个量子态读出”。
可以说“完成三组几何的电磁与量子分析，量化频移与单模Purcell估算的权衡”。

避免交叉验证的下一步：扫描结电感/失谐，跨过读出模态，独立提取耦合；再检查多模、
加载一致性、真实损耗、状态条件响应和读出噪声。

## 单位提醒

教材α为能量，表格写α/h；g也为能量，Purcell公式使用ℏΔ/g。
教材式(24.13)的 Δf = fᵣ/Qᵣ 可用。若换算能量衰减到1/e的时间，标准关系是
τ = Qᵣ/ωᵣ = 1/(2πΔf)，应注意教材式(24.5)的时间表述存在2π偏差。
